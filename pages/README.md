# GitLab Pages

此目录是 GitLab Pages 的公开站点源码。

- `index.html`：为什么使用 GitLab，以及面向新手的 GitLab × AI 完整首次上手 SOP。页面用非技术语言解释 GitLab 的通用 AI 入口、完整协作能力和唯一真理源价值，并串起登录与令牌、在指定 Group 新建业务项目、复制地址、交给 AI、新建任务分支、修改检查、合并请求七个步骤。业务仓库不得散落在个人空间，必须遵循统一 Group、负责人、可见范围和模板规则。
- `assets/`：GitLab 令牌配置的原始操作截图。

.github/workflows/pages.yml` 只发布 `pages/` 目录。不要把整个仓库自动复制到 Pages，避免未来的草稿或其他附件被意外公开。
